# Домашняя лаборатория

Учебный проект: виртуальная сеть в VirtualBox, как в небольшой компании.

## Цель
Научиться разворачивать и администрировать серверы Windows и Linux.

## Состав лаборатории
- Windows Server: Active Directory, DNS, DHCP
- Linux-сервер: SSH, файловый сервер
- Клиентская машина, введённая в домен

## План
- [ ] Установить VirtualBox и создать виртуальные машины
- [ ] Настроить сеть между машинами
- [ ] Поднять домен Active Directory
- [ ] Настроить DNS и DHCP
- [ ] Ввести клиента в домен
- [ ] Создать пользователей и групповые политики
- [ ] Настроить Linux-сервер и SSH

Здесь буду описывать шаги, команды и решённые проблемы.
